# Security Policy

If you believe you have discovered a security issue in BlockCraft Launcher, please report it privately and responsibly.

Please do not open a public issue for a vulnerability.

How to report:
- Email the maintainer at the repository's configured security contact, or
- Open a private report through GitHub's security advisory flow if available.

Please include:
- A description of the issue
- A reproduction path or steps
- The affected component or file
- Any known impact
- Suggested mitigation

We will acknowledge valid reports as quickly as possible and work with you to resolve them.

Do not commit secrets, private keys, access tokens, keystores, or Microsoft credentials to the repository.
